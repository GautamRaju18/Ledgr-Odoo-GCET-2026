LEDGR — LOGO PACK (Option C · "Rising l")

COLOURS
  Brand purple  #714B67   primary logo, app icon background
  Brand dark    #5A3A52   dark variant
  White         #FFFFFF   logo on the purple sidebar / dark backgrounds

WHICH FILE TO USE
  ledgr-logo-primary       Purple logo on white or light backgrounds (default)
  ledgr-logo-white         White logo, transparent — use on the purple sidebar
  ledgr-logo-on-purple     White logo on a purple rounded plate (social, slides)
  ledgr-logo-dark          Brand-dark version for light backgrounds
  ledgr-logo-black         One-colour black for print, faxes, stamps
  ledgr-logo-stacked(-white)  Mark above wordmark, for square spaces
  ledgr-mark-purple/white  The "l" arrow mark alone
  ledgr-app-icon(-circle)  App icon / avatar

FORMATS
  SVG/     Vector — web and app (infinitely scalable; text is outlined)
  PDF/     Vector — print, Word/PowerPoint, sending to printers
  PNG/     Transparent raster in several widths (logos) or sizes (icons)
  Favicon/ favicon.ico, favicon.svg, 16/32 px, apple-touch-icon (180),
           android-chrome 192/512

RULES
  Clear space: keep at least the height of the arrow head empty around the logo.
  Minimum size: mark 20 px tall on screen; full logo 96 px wide.
  Don't stretch, recolour outside the palette, add shadows or retype the wordmark.
